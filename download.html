Install

설치하고
첫 회의 녹음하기

  1. 앱 설치

    내려받은 .dmg 파일을 열고 ZeroNote를 응용 프로그램 폴더로 끌어다 놓으세요.

  2. 처음 열기

    베타 빌드는 아직 Apple 공증 전이라 처음 열 때 경고가 나올 수 있어요. 시스템 설정 → 개인정보 보호 및 보안에서 '확인 없이 열기'를 누르세요.

  3. 권한 허용

    녹음을 처음 시작하면 마이크 권한을 묻습니다. 화상회의 상대방 목소리까지 녹음하려면 '화면 및 시스템 오디오 녹음' 권한도 허용해 주세요. 화면 영상은 저장하지 않아요.

  4. 모델 내려받기

    첫 실행 안내에 따라 음성 인식 모델(Large v3 Turbo, 574MB)과 요약 모델(2.5GB부터)을 내려받으면 준비가 끝납니다. 한 번만 받으면 돼요. 나중에 설정에서 받아도 됩니다.

  5. 녹음 시작

    '녹음 시작'을 누르면 받아쓰기가 시작되고, 녹음이 끝나면 이 컴퓨터의 AI가 요약합니다. 더 정확한 요약을 원하면 설정 → 요약 AI에서 내 Claude나 ChatGPT 계정을 연결하세요.

  1. 설치 프로그램 실행

    내려받은 .exe 파일을 실행하고 안내에 따라 설치하세요.

  2. 보안 경고가 나오면

    베타 빌드는 아직 코드 서명 전이라 'Windows의 PC 보호' 창이 뜰 수 있어요. '추가 정보'를 누른 뒤 '실행'을 누르세요.

  3. 음성 인식 모델 내려받기

    전사 엔진은 설치 파일에 포함되어 있습니다. 첫 실행 안내에서 음성 인식 모델을 내려받으세요. 사양이 낮은 PC라면 Small 모델이 더 빠릅니다.

  4. 녹음 시작

    '녹음 시작'을 누르면 마이크와 컴퓨터 소리를 함께 받아 적습니다. Windows는 별도 권한 없이 컴퓨터 소리를 녹음할 수 있어요.
