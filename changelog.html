변경 기록

v0.4.42026. 11. 26.

업데이트 설치와 재시작

  • 설치 후 재시작을 누르면 macOS와 Windows에서 업데이트 파일을 검증하고 기존 위치에 설치한 뒤 앱을 다시 엽니다. 0.4.3에서 이번 버전으로 올릴 때만 수동 설치가 필요합니다. macOS에서는 앱이 쓰기 가능한 폴더에 있어야 합니다.
  • Mac에서는 API 키를 기본적으로 앱을 종료할 때까지만 기억합니다. 저장한 키는 설정 → 일반 → 이 Mac의 키체인 사용에서 켤 수 있고, 설정을 열 때마다 키체인을 조회하던 동작을 개선했습니다.
  • 백업을 덮어쓰기 전에 새 ZIP 파일의 모든 항목을 확인합니다.
  • 전사에 실패한 구간을 회의 화면에 표시합니다. 원본 녹음이 있으면 해당 구간만 다시 받아쓰고 요약할 수 있습니다.
  • 긴 오디오를 구간별로 읽으며 가져오기 진행 상황을 표시합니다.
  • 설치 파일에 포함하는 전사·요약 엔진 버전을 고정했습니다.
  • 앱과 웹사이트에 새 흑백 로고를 적용했습니다.
v0.4.32026. 11. 24.

회의 요약을 Slack에 자동 전송

  • Slack 자동 보내기: 새 회의 요약이 끝나면 연결한 채널로 전송 (설정에서 켬)
v0.4.22026. 11. 23.

더 간편해진 Slack 연결

  • Slack 로그인으로 연결: 채널만 고르면 끝 (웹훅 주소 직접 입력도 가능)
  • 새 드롭다운: 화살표 잘림 수정, 메뉴가 창 안에서 잘리지 않음
  • 새 설치 화면: 끌어다 놓기와 처음 열기 방법 안내
  • 설정·회의록 화면의 입력칸 모양 통일
v0.4.12026. 11. 17.

첫 회의록까지 더 빠르게

  • 첫 실행 안내에서 음성 인식 모델과 가벼운 요약 모델을 자동으로 받기
  • 모델을 받는 동안 녹음한 회의도 준비되는 대로 받아 적고 요약
  • 설정에 개인정보처리방침 링크
v0.4.02026. 11. 17.

익명 사용 통계 설정

  • 익명 사용 통계 (선택): 첫 실행에서 묻고, 설정에서 언제든 끌 수 있음
  • 회의 내용·제목·파일 이름은 통계에 들어가지 않음
v0.3.02026. 11. 15.

내 컴퓨터에서 AI 요약

  • 무료 로컬 AI 요약이 기본: 앱에 든 엔진으로 이 컴퓨터에서 요약·질문
  • 요약 모델 한 번 내려받기 (Qwen3 4B / Gemma 3 12B, 메모리에 맞춰 추천)
  • 긴 회의는 나눠서 요약한 뒤 합치기
  • Claude·ChatGPT는 "더 정확한 요약" 옵션으로
v0.2.02026. 11. 15.

Intel Mac 지원과 회의록 검색

  • Intel Mac 지원, 새 버전 알림
  • 화자 구분(나 / 상대), 스크립트 편집, 용어·바꾸기 규칙
  • 회의록 형식 선택, 전체 검색, 회의록에 질문하기
  • 폴더·태그, 할 일 모아보기, PDF·SRT·Slack·Notion 내보내기
  • 회의 감지 알림, 메뉴 막대와 단축키로 녹음
  • 첫 실행 안내, 다크 모드, 영어 화면, 백업과 자동 정리
