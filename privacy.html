개인정보처리방침

시행일 2026년 11월 27일

ZeroNote(이하 "서비스")는 회의를 녹음하고 받아 적어 회의록으로 정리하는 데스크톱 앱과 그 소개 웹사이트(zeronote-app.netlify.app)입니다. ZeroPlus(이하 "운영자")는 사용자의 회의 내용을 받지 않도록 서비스를 만들었습니다. 이 문서는 그래도 처리되는 정보가 무엇인지, 처리되지 않는 정보가 무엇인지 설명합니다.

한눈에 보기

  • 회의 음성과 회의록은 기본으로 사용자 컴퓨터에 저장됩니다. 개인 Google Drive 동기화를 켜면 텍스트 회의록이 사용자의 Drive에도 저장됩니다.
  • 앱은 사용자가 허용한 경우에만 익명 사용 통계(어떤 기능을 썼는지)를 보냅니다. 회의 내용, 제목, 파일 이름은 포함되지 않습니다.
  • 웹사이트는 쿠키 없이 방문 수와 다운로드 클릭 수를 셉니다.
  • Windows 출시 알림 신청은 종료되었습니다. 기존 신청자의 이메일 보관 기간은 아래 3항에 안내되어 있습니다.
  • 로그인 없이 녹음할 수 있습니다. Google 로그인을 선택하면 Firebase Authentication에서 ZeroNote 회원 계정을 관리합니다.

1. 앱이 처리하는 정보

사용자의 컴퓨터에 저장되는 정보

녹음한 음성, 받아 적은 기록, 요약과 할 일, 설정, 연결한 Claude·OpenAI API 키는 사용자의 컴퓨터에 저장됩니다. API 키는 운영체제의 보안 저장소로 암호화합니다. 받아쓰기와 기본 요약은 앱에 든 엔진으로 이 컴퓨터에서 처리합니다. 기기에 보관한 회의 파일은 설정의 데이터 위치에서 삭제할 수 있습니다.

Google 계정과 개인 Drive 동기화 (선택)

Google로 로그인하면 운영자는 Firebase Authentication에서 이메일, 회원 식별자, 가입 및 로그인 시각을 확인할 수 있습니다. 로그인 유지에 동의하면 앱은 운영체제 암호화를 사용해 로그인 정보를 이 기기에 보관합니다.

설정 → 계정에서 Drive 동기화를 켜면 완료된 회의의 제목, 폴더, 태그, 화자, 전사문, 요약과 할 일이 사용자 개인 Drive의 ZeroNote 전용 공간에 저장됩니다. 녹음 원본은 기기에 보관합니다. ZeroNote는 Google에서 받은 정보를 로그인, 회원 관리 및 사용자가 켠 동기화에 사용합니다. 운영자의 회원 관리 화면에는 회의 내용이 표시되지 않습니다.

설정 → 계정에서 동기화를 일시 중지하거나 회원 탈퇴를 선택할 수 있습니다. 탈퇴하면 Firebase의 회원 계정을 삭제합니다. 개인 Drive의 회의록은 기본으로 보관하며, 탈퇴 화면에서 영구 삭제를 선택할 수 있습니다. 기기에 보관한 회의록은 앱에서 직접 관리합니다.

Google 캘린더 연결 (지원 버전에서 선택)

Google 캘린더를 연결하면 ZeroNote가 Google 계정의 기본 캘린더에서 앞으로 7일 동안의 일정 제목, 식별자, 시작·종료 시간, 취소 및 참석 응답 상태를 읽습니다. 이 정보는 홈 화면에 일정을 표시하고 사용자가 자동 녹음을 켠 일정의 시작 시간을 확인하는 데 사용합니다. 앱은 Google 캘린더의 일정을 변경하지 않습니다.

자동 녹음을 켠 일정의 식별자와 시간은 이 기기에 저장됩니다. 앱을 실행 중일 때 예약 녹음이 시작되며, 일정 제목이 기기에 저장되는 회의록의 제목으로 쓰입니다. 개인 Drive 동기화도 켜져 있으면 해당 회의록의 제목과 텍스트가 사용자 개인 Drive에 저장됩니다. 운영자는 캘린더 일정과 녹음 내용을 받지 않습니다.

설정 → 계정에서 Google 캘린더 연결을 끄면 일정 표시와 자동 녹음 예약 설정이 지워집니다. 이미 저장된 회의록은 앱에서 관리할 수 있습니다. Google 계정의 보안 설정에서 ZeroNote의 접근 권한도 철회할 수 있습니다.

익명 사용 통계 (선택)

앱을 더 낫게 만들기 위해, 사용자가 허용한 경우 아래 정보를 보냅니다. 새로 설치하면 첫 실행 안내의 첫 화면에서 묻고(기본으로 켜져 있음), 기존 사용자에게는 홈 화면에서 한 번 묻습니다. 답하기 전에는 보내지 않으며, 설정 → 일반 → "익명 사용 통계 보내기"에서 언제든 끌 수 있습니다. 끄면 아직 보내지 않은 기록도 버립니다.

  • 보내는 것: 기능 사용 이벤트 이름(예: 녹음 시작, 받아쓰기 완료, 요약 완료), 분류 값(예: 회의 길이 구간, 요약 엔진 종류, 오류 종류), 앱 버전, 운영체제 종류와 버전, 칩 종류, 메모리 크기, 화면 언어
  • 구분하는 방법: 설치할 때 만드는 무작위 ID. 이름, 이메일, 기기 이름과 연결되지 않습니다.
  • 보내지 않는 것: 회의 음성과 내용, 회의 제목, 파일 이름과 경로, 오류 메시지 원문, API 키, IP 주소 기반 위치

사용자가 직접 연결하거나 고른 서비스

아래 경우에는 사용자의 선택에 따라 해당 서비스로 정보가 직접 전송됩니다. 운영자는 이 정보를 받지 않으며, 각 서비스의 개인정보처리방침이 적용됩니다.

  • Claude(Anthropic) 또는 ChatGPT(OpenAI) 계정 연결: 요약하거나 질문할 때 받아 적은 기록이 사용자의 계정으로 전송됩니다.
  • Ollama: 사용자가 지정한 주소로 기록이 전송됩니다.
  • Slack·Notion으로 내보내기: 내보내기를 누른 회의록이 사용자가 지정한 곳으로 전송됩니다.

모델 내려받기와 새 버전 확인

음성 인식 모델과 요약 모델은 Hugging Face에서, 새 버전 정보는 GitHub에서 받습니다. 이때 일반적인 인터넷 요청처럼 해당 서비스에 IP 주소가 전달될 수 있습니다. 새 버전 확인은 설정에서 끌 수 있습니다.

2. 웹사이트가 처리하는 정보

  • 방문 통계: 페이지 보기, 페이지를 떠난 시점, 다운로드 버튼 클릭을 셉니다. 쿠키 대신 탭을 닫으면 사라지는 브라우저 저장소를 쓰고, 화면 녹화와 자동 클릭 수집은 하지 않으며, IP 주소는 저장하지 않도록 설정했습니다.
  • 호스팅: 웹사이트는 Netlify에서 제공되며, Netlify가 보안과 운영을 위해 접속 기록을 처리할 수 있습니다.

3. 기존 Windows 출시 알림 신청

  • 받는 정보: 이메일 주소
  • 목적: Windows 버전이 나왔을 때 한 번 알리기. 광고나 다른 목적으로 쓰지 않습니다.
  • 보관 기간: 출시 알림을 보낸 뒤 30일 안에 지웁니다. 신청을 취소하면 바로 지웁니다.

4. 처리를 맡기는 곳과 국외 이전

운영자는 아래 업체에 정보 처리를 맡깁니다. 기존 익명 통계와 웹 호스팅 정보는 미국으로 전송되어 저장됩니다. Google 로그인 이용 시 회원 계정 처리를 Google에 위탁합니다.

전송은 서비스를 이용하거나 신청할 때 인터넷으로 이뤄집니다. 앱의 사용 통계와 Google 로그인은 각각 선택할 수 있습니다.

5. 사용자의 권리

사용자는 언제든 익명 통계를 끌 수 있고, 출시 알림 신청의 확인·삭제를 요청할 수 있습니다. 익명 통계는 사람을 알아볼 수 없는 무작위 ID로만 저장되므로, 삭제를 원하면 앱 데이터 폴더의 install-id 값을 함께 알려 주세요. 요청은 아래 문의처로 받으며, 받은 날부터 10일 안에 처리합니다.

6. 만 14세 미만

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 출시 알림 신청은 만 14세 이상만 할 수 있습니다.
