개인정보처리방침

시행일 2026년 11월 17일

ZeroNote(이하 "서비스")는 회의를 녹음하고 받아 적어 회의록으로 정리하는 데스크톱 앱과 그 소개 웹사이트(zeronote-app.netlify.app)입니다. ZeroPlus(이하 "운영자")는 사용자의 회의 내용을 받지 않도록 서비스를 만들었습니다. 이 문서는 그래도 처리되는 정보가 무엇인지, 처리되지 않는 정보가 무엇인지 설명합니다.

한눈에 보기

  • 회의 음성, 받아 적은 기록, 회의록은 사용자의 컴퓨터에만 저장되며 운영자에게 전송되지 않습니다.
  • 앱은 사용자가 허용한 경우에만 익명 사용 통계(어떤 기능을 썼는지)를 보냅니다. 회의 내용, 제목, 파일 이름은 포함되지 않습니다.
  • 웹사이트는 쿠키 없이 방문 수와 다운로드 클릭 수를 셉니다.
  • 이메일 주소는 Windows 출시 알림을 신청한 경우에만 받으며, 알림을 보낸 뒤 지웁니다.
  • 회원가입이 없어 이름, 전화번호, 계정 정보를 받지 않습니다.

1. 앱이 처리하는 정보

사용자의 컴퓨터에만 저장되는 정보

녹음한 음성, 받아 적은 기록, 요약과 할 일, 설정, 연결한 Claude·OpenAI API 키는 사용자의 컴퓨터에만 저장됩니다. API 키는 운영체제의 보안 저장소로 암호화합니다. 받아쓰기와 기본 요약은 앱에 든 엔진으로 이 컴퓨터에서 처리합니다. 앱을 지우거나 설정의 데이터 위치에서 파일을 지우면 함께 삭제됩니다.

익명 사용 통계 (선택)

앱을 더 낫게 만들기 위해, 사용자가 허용한 경우 아래 정보를 보냅니다. 새로 설치하면 첫 실행 안내의 첫 화면에서 묻고(기본으로 켜져 있음), 기존 사용자에게는 홈 화면에서 한 번 묻습니다. 답하기 전에는 보내지 않으며, 설정 → 일반 → "익명 사용 통계 보내기"에서 언제든 끌 수 있습니다. 끄면 아직 보내지 않은 기록도 버립니다.

  • 보내는 것: 기능 사용 이벤트 이름(예: 녹음 시작, 받아쓰기 완료, 요약 완료), 분류 값(예: 회의 길이 구간, 요약 엔진 종류, 오류 종류), 앱 버전, 운영체제 종류와 버전, 칩 종류, 메모리 크기, 화면 언어
  • 구분하는 방법: 설치할 때 만드는 무작위 ID. 이름, 이메일, 기기 이름과 연결되지 않습니다.
  • 보내지 않는 것: 회의 음성과 내용, 회의 제목, 파일 이름과 경로, 오류 메시지 원문, API 키, IP 주소 기반 위치

사용자가 직접 연결하거나 고른 서비스

아래 경우에는 사용자의 선택에 따라 해당 서비스로 정보가 직접 전송됩니다. 운영자는 이 정보를 받지 않으며, 각 서비스의 개인정보처리방침이 적용됩니다.

  • Claude(Anthropic) 또는 ChatGPT(OpenAI) 계정 연결: 요약하거나 질문할 때 받아 적은 기록이 사용자의 계정으로 전송됩니다.
  • Ollama: 사용자가 지정한 주소로 기록이 전송됩니다.
  • Slack·Notion으로 내보내기: 내보내기를 누른 회의록이 사용자가 지정한 곳으로 전송됩니다.

모델 내려받기와 새 버전 확인

음성 인식 모델과 요약 모델은 Hugging Face에서, 새 버전 정보는 GitHub에서 받습니다. 이때 일반적인 인터넷 요청처럼 해당 서비스에 IP 주소가 전달될 수 있습니다. 새 버전 확인은 설정에서 끌 수 있습니다.

2. 웹사이트가 처리하는 정보

  • 방문 통계: 페이지 보기, 페이지를 떠난 시점, 다운로드 버튼 클릭을 셉니다. 쿠키 대신 탭을 닫으면 사라지는 브라우저 저장소를 쓰고, 화면 녹화와 자동 클릭 수집은 하지 않으며, IP 주소는 저장하지 않도록 설정했습니다.
  • 호스팅: 웹사이트는 Netlify에서 제공되며, Netlify가 보안과 운영을 위해 접속 기록을 처리할 수 있습니다.

3. Windows 출시 알림 신청

  • 받는 정보: 이메일 주소
  • 목적: Windows 버전이 나왔을 때 한 번 알리기. 광고나 다른 목적으로 쓰지 않습니다.
  • 보관 기간: 출시 알림을 보낸 뒤 30일 안에 지웁니다. 신청을 취소하면 바로 지웁니다.

4. 처리를 맡기는 곳과 국외 이전

운영자는 아래 업체에 정보 처리를 맡깁니다. 두 업체 모두 미국에 서버가 있어, 정보가 미국으로 전송되어 저장됩니다.

업체맡기는 일정보보관
PostHog Inc. (미국)앱·웹사이트 익명 통계 저장과 분석위 1, 2의 익명 통계최대 1년
Netlify Inc. (미국)웹사이트 호스팅, 출시 알림 신청 저장접속 기록, 신청한 이메일 주소위 3의 기간

전송은 서비스를 이용하거나 신청할 때 인터넷으로 이뤄집니다. 통계를 끄거나 신청하지 않으면 해당 정보는 전송되지 않습니다.

5. 사용자의 권리

사용자는 언제든 익명 통계를 끌 수 있고, 출시 알림 신청의 확인·삭제를 요청할 수 있습니다. 익명 통계는 사람을 알아볼 수 없는 무작위 ID로만 저장되므로, 삭제를 원하면 앱 데이터 폴더의 install-id 값을 함께 알려 주세요. 요청은 아래 문의처로 받으며, 받은 날부터 10일 안에 처리합니다.

6. 만 14세 미만

서비스는 만 14세 미만 아동을 대상으로 하지 않으며, 출시 알림 신청은 만 14세 이상만 할 수 있습니다.
